# Security policy

## Supported releases

Only the latest Durlo alpha receives best-effort security fixes. Alpha releases are not a
production-support commitment, and the project does not promise a response or remediation-time
SLA.

## Report a vulnerability

Report vulnerabilities exclusively through GitHub private vulnerability reporting for
`Pankaj3112/durlo` once that repository feature is enabled. Do not include vulnerability details in
a public issue, discussion, or pull request.

Private vulnerability reporting is a maintainer-controlled repository setting. Until GitHub shows
the private reporting form on the repository's Security page, Durlo has no public confidential
reporting channel. General, non-sensitive defects may be filed in the public issue tracker.

Durlo has no security email address, paid support channel, or guaranteed disclosure timeline.
