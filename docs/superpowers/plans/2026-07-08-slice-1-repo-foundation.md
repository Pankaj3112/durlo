# Slice 1 Repo Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the Durlo v1 monorepo foundation so packages build and a smoke test imports `@durlo/core`.

**Architecture:** The repo becomes a `pnpm` workspace with package directories under `packages/*`. Root tooling owns orchestration, lint, format, and test configuration, while each publishable package owns its package metadata, TypeScript config, source entrypoint, and build script. Slice 1 adds only package-level no-op exports plus a minimal `Durlo` class; runtime behavior stays out of scope.

**Tech Stack:** `pnpm@11.10.0`, Node.js `>=22`, TypeScript `^5.9.3`, `turbo@^2.10.4`, `tsup@^8.5.1`, `vitest@^4.1.10`, `eslint@^9.39.4`, `typescript-eslint@^8.63.0`, Prettier `^3.9.4`.

## Global Constraints

- Package manager: `pnpm` workspaces.
- Task runner: `turbo`.
- Runtime floor: Node.js `>=22`.
- Language: TypeScript in strict mode.
- Package build: `tsup`.
- Tests: `Vitest`.
- Linting: `ESLint 9` flat config with `typescript-eslint`.
- Formatting: Prettier.
- Public package names: `@durlo/core`, `@durlo/postgres`, and `durlo`.
- Do not add real task, workflow, run, worker, retry, serialization, or adapter behavior.
- Do not add Postgres migrations or database code.
- Do not add events, cron, distributed concurrency, framework adapters, dashboard, or demo app work.
- Follow TDD for source behavior: write the failing import/export test before adding the source export it exercises.
